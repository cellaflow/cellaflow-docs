# Changelog

---

## Python SDK

### v0.3.0 — Latest

- ✅ `IdempotencyScope.SCOPE_SHARED` — agents in **different sessions**, on different workflows and
  versions, converge on one execution within a named coordination domain
- ✅ **Replay verification** — a resumed run that diverges from its recorded history raises
  `NondeterministicWorkflowError` rather than returning the result recorded at that position
- ✅ **Graph-position arbitration** — replicas that disagree about a step's arguments raise
  `DivergentStepError` *before* the side effect runs
- ✅ Callers adopt the engine's reported sequence after a cache hit
- ✅ Concurrent `CellaflowSaver` instances on one `thread_id` commit against a refreshed sequence
- ✅ Lease renewal failures explain what happened and what to do about it

Requires no engine upgrade — the new request fields are optional and an older engine ignores
them.

### v0.2.0

- ✅ `@workflow`, `@step`, `@tool` decorators with full `async def` support
- ✅ `CellaflowSaver` — drop-in LangGraph checkpointer with time-travel and crash recovery
- ✅ RFC 8785 Canonical JSON + SHA-256 idempotency key derivation
- ✅ Agent-scoped idempotency (`SCOPE_SESSION_WIDE`, `SCOPE_AGENT_PRIVATE`, `SCOPE_STEP_LOCAL`)
- ✅ Background lease heartbeat management with fencing token validation
- ✅ MessagePack serialization for all state payloads (no pickle, no RCE vectors)
- ✅ `contextvars` isolation — safe for concurrent async workflows in the same process
- ✅ Low-level `CellaflowClient` for manual session management

Install: [`pip install cellaflow`](https://pypi.org/project/cellaflow/)

## CellaFlow Engine

### Latest

- ✅ `WorkflowEngineService` — `StartSession`, `CommitStep`, `GetGraph`
- ✅ `IdempotencyService` — `CheckIdempotencyCache`, `RenewLease`, `ReleaseLease`
- ✅ RocksDB-backed append-only event graph
- ✅ Sequence ordering guard — optimistic concurrency for step commits
- ✅ Graph-position arbitration — a lease is refused before execution when the position is already
  committed, or claimed by a different step identity
- ✅ Maximum lease lifetime (`CELLAFLOW_MAX_LEASE_LIFETIME_MS`) — a worker that hangs while still
  heartbeating is eventually reclaimed, with fencing tokens making the reclaim safe
- ✅ Boot recovery — session reconstruction and timer respawning on startup
- ✅ TLS support (cert + key via environment variables)
- ✅ Bearer token and `x-api-key` authentication interceptor
- ✅ gRPC reflection (v1 + v1alpha)
- ✅ OTLP telemetry (traces + metrics)
- ✅ Health check HTTP server (`/health/ready`)

Docker: `ghcr.io/cellaflow/cellaflow:latest`
