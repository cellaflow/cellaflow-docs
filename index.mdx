# The Execution Ledger for Multi-Agent AI

CellaFlow is a systems-grade Rust execution ledger that makes AI agent workflows **durable, idempotent, and crash-proof** — at roughly **2ms per committed step**.

<Note>
Measured single-writer against `ghcr.io/cellaflow/cellaflow:latest` on a 2018 Intel MacBook Pro: `CommitStep` p50 **1.6ms**, p99 **2.8ms**. Almost all of that is the gRPC round trip — the durable write itself does not register above the noise floor.
</Note>

Add three decorators to your Python code. That's it.

```python
from cellaflow import workflow, step, tool, IdempotencyScope

@tool(scope=IdempotencyScope.SCOPE_SESSION_WIDE)
def search_web(query: str) -> dict:
    """Calls an external API. Runs once — even if 50 agents ask for the same result."""
    return {"query": query, "results": ["CellaFlow Overview", "Durable Execution Docs"]}

@step
def summarize(data: dict) -> str:
    return f"Processed {len(data['results'])} results for '{data['query']}'"

@workflow(version="1.0.0")
def research_agent(topic: str) -> str:
    data = search_web(topic)
    return summarize(data)

result = research_agent("autonomous AI architectures")
```

<Note>
**What just happened?**

- ✅ Every step result was durably committed to CellaFlow's append-only event graph (backed by RocksDB)
- ✅ If this process crashes mid-run, restarting it with the same session ID resumes **exactly** where it stopped — zero re-execution of completed steps
- ✅ The `@tool` call is idempotent — if 50 agents in a swarm call `search_web` with the same query, **1 HTTP request runs**, and the result is broadcast to all 49 waiting agents (singleflight herd collapse)
</Note>

## What makes CellaFlow different?

<CardGroup cols={2}>
  <Card title="Durable Execution" icon="shield-check">
    Workflows survive process crashes, pod evictions, and network splits. Pick up mid-step — not from scratch.
  </Card>
  <Card title="Singleflight Deduplication" icon="layers">
    50 agents requesting the same tool call = 1 execution. In-memory broadcast eliminates redundant API spend.
  </Card>
  <Card title="Agent-Scoped Idempotency" icon="fingerprint">
